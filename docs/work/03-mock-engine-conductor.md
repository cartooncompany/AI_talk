# 03. Mock 엔진 + Conductor

- **날짜**: 2026-08-20
- **이슈**: [#6](https://github.com/cartooncompany/AI_talk/issues/6)
- **상태**: 완료

## 목표

UI 없이 콘솔에서 게임 한 판을 끝까지 돌린다. 계획안에서 잡은 실질적 검증 지점.

## 한 일

### 1. 시드 기반 난수 (`src/core/random.ts`)

mulberry32. 시드를 고정하면 같은 게임이 재현되므로 테스트가 안정적이고
버그 재현도 쉽다.

시드 직후 첫 출력이 시드값에 강하게 좌우되는 성질이 있어, 상태를 8회 미리
돌리는 워밍업을 넣었다. 이것 없이는 인접한 시드끼리 초반 난수가 비슷해
게임이 같은 방식으로 시작되는 일이 잦았다.

### 2. Mock 엔진 (`src/core/engines/mock.ts`)

사전에서 규칙에 맞는 단어를 고르되, 일정 확률(기본 4%)로 일부러 틀린다.
실수가 없으면 승패 판정 경로를 검증할 수 없기 때문이다.

실수 유형 4가지 — 각각 Scenario의 다른 판정 경로를 자극한다.

| 유형 | 내용 |
|---|---|
| `wrong-start` | 엉뚱한 글자로 시작하는 실제 단어 |
| `repeat` | 이미 나온 단어 |
| `single-char` | 규칙엔 맞지만 한 글자 |
| `not-a-word` | 사전에 없는 말 |

후보를 고를 때 **상대가 이어받을 수 있는 단어를 우선**한다
(`survivingCandidates`). 사전이 작아 아무 단어나 고르면 금방 막다른 길에
닿기 때문이다. 자세한 경위는 [이슈 002](../issues/002-short-games.md) 참고.

테스트용 `createScriptedEngine`도 함께 넣었다. 정해진 순서대로 발화하므로
Conductor 테스트에서 결과를 예측할 수 있다.

### 3. Conductor (`src/core/conductor.ts`)

턴 루프와 상태 머신. 발화 생성도 규칙 판정도 직접 하지 않고 인터페이스로만
호출하므로, Mock을 실제 API로 바꿔도 이 파일은 그대로다.

```
idle → running → (paused ⇄ running) → finished
```

UI가 구독할 이벤트를 방출한다.

| 이벤트 | 시점 |
|---|---|
| `start` | 게임 시작. 시작 단어를 담는다 |
| `thinking` | 발화 직전. 타이핑 인디케이터를 켜는 지점 |
| `turn` | 턴 종료. 판정 결과 포함 |
| `finish` | 게임 종료 |
| `status` | 일시정지·재개 |

**엔진 오류를 게임 중단으로 만들지 않는다.** 실제 API에서는 네트워크 오류가
날 수 있는데, 그때 대화가 멈춰버리면 관전이 끊긴다. 발화하지 못한 것으로
처리해 규칙 위반으로 판정하고 게임을 마무리한다.

`pause()`는 진행 중인 턴을 끝까지 마친 뒤 멈춘다. 턴 중간에 끊으면 이미
호출한 API 응답을 버리게 되기 때문이다.

### 4. 콘솔 데모 (`scripts/demo.mjs`)

```bash
npm run demo         # 무작위 시드
npm run demo -- 42   # 시드 고정
```

실행 예 (seed=7):

```
  시작 단어: 「겨울」

   1.   🟠 Claude    울음
   2.   🟢 GPT       음악
   3.   🟠 Claude    악기
   4.   🟢 GPT       기린
   5.   🟠 Claude    인사      ← 두음법칙 (린 → 인)
   6.   🟢 GPT       사자
   7.   🟠 Claude    자유
   8.   🟢 GPT       유리
   9.   🟠 Claude    이불      ← 두음법칙 (리 → 이)
  10.   🟢 GPT       불꽃
  11.   🟠 Claude    꽃병
  12. ✗ 🟢 GPT       샬라   ← '병'(으)로 시작해야 하는데 '샬'로 시작했다

  GPT의 '샬라' — ... Claude 승리.
  총 12턴 · 종료 사유: rule-violation
```

2단계에서 만든 두음법칙이 실전에서 동작하는 것도 확인된다 (5번, 9번 턴).
